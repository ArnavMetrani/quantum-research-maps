# quantum-research-maps
Databases of quantum research groups. Inspired from:
- (https://quantumoptics.at/en/links/ion-trapping-worldwide.html)
- (https://everycoldatom.com/)

For cold atoms, I wanted to create a version that was a bit less sluggish to load and sylistically different.

# For issue reporting:
Open an issue to report an error (incorrect characterisation, broken/defunct/changed URL, incorrect corrdinates, dissolved group, etc. ) or a missing group. Use pull requests as well.

# For suggestions:
Use the issues section or pull requests.

Data was collated from the wonderful repository of [zgosar](https://github.com/zgosar): [EveryColdAtom](https://github.com/zgosar/EveryColdAtom). Rest of the details were obtained from the master list mainained on the UToronto site: https://ucan.physics.utoronto.ca/research-groups/

Made using claude.ai by Anthropic. This is a very rough implementation, so feel free to build a better one!
